# .github

Organisation-wide defaults for [OpenCourant](https://github.com/OpenCourant).

| Path | Effect |
| --- | --- |
| `profile/README.md` | Rendered as the organisation landing page at [github.com/OpenCourant](https://github.com/OpenCourant). |
| `SUPPORT.md` | Default support routing, applied to every OpenCourant repository that does not define its own. |

Files here are fallbacks only. A repository's own community health files
always take precedence.
