# Support

Thanks for using OpenCourant. Here is where to go, depending on what you need.

## Questions, ideas, and discussion

**[OpenCourant Discussions](https://github.com/orgs/OpenCourant/discussions)**
is the project forum and the best place to start. Use it for how-to questions,
modelling problems, proposals, release feedback, and anything that benefits
from being searchable later.

## Realtime chat

For quick back-and-forth, join
[`#opencourant`](https://chat.rockylinux.org/rocky-linux/channels/opencourant)
on the Rocky Linux Mattermost. Chat is useful, but it is not archived in a way
people can find later. If the answer is worth keeping, put it on the forum.

## Bugs and tracked work

Open an issue in the repository the problem belongs to:

| | |
| --- | --- |
| Solver behaviour, crashes, wrong results | [OpenCourant/OpenCourant](https://github.com/OpenCourant/OpenCourant/issues) |
| Converters, launcher GUI, SDK | [OpenCourant/Tools](https://github.com/OpenCourant/Tools/issues) |
| Build libraries | [OpenCourant/extlib](https://github.com/OpenCourant/extlib/issues) |
| CI container images | [OpenCourant/ci-images](https://github.com/OpenCourant/ci-images/issues) |
| The website | [OpenCourant/opencourant.org](https://github.com/OpenCourant/opencourant.org/issues) |

For solver bugs, please include the OpenCourant version or release tag, your
platform, and an input deck that reproduces the problem if you can share one.

## Security

**Do not report security problems in public issues or discussions.** Email
[hello@opencourant.org](mailto:hello@opencourant.org), or use the private
vulnerability reporting available from a repository's Security tab.
